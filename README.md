# MyMochiMate Terms & Conditions Website

Website sederhana untuk menampilkan halaman **Syarat dan Ketentuan** aplikasi **MyMochiMate**.  
Website ini dibuat menggunakan HTML dan CSS, serta dirancang dengan tampilan pastel yang sesuai dengan tema aplikasi healthy lifestyle reminder.

## Deskripsi

MyMochiMate Terms & Conditions Website berfungsi sebagai halaman informasi resmi yang berisi aturan penggunaan aplikasi MyMochiMate. Halaman ini dapat diakses oleh pengguna melalui link yang tersedia pada halaman register aplikasi.

## Fitur

- Halaman Syarat dan Ketentuan
- Desain responsive untuk desktop dan mobile
- Tampilan pastel dengan dekorasi visual
- Logo aplikasi
- Favicon website
- Footer copyright
